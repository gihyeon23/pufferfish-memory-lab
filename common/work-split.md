# 작업 분담 (나 vs Claude)

교수님 피드백(2026-11): 모든 걸 AI로 하지 말 것. 생각·판단은 내가, 읽기 힘든 대량 출력은 Claude가.

## 내가 직접

- 논문 읽기·해석, 가설 세우기
- 실험 설계: 바꿀 변수·조건·회차 결정
- 실험 실행: ssh 접속, 설정 수정, 명령 실행(sudo 포함)
- 결과 해석·결론 쓰기 (`steps/` 문서의 "결론"·"해석" 부분)
- 랩미팅 PPT·발표, 교수님·저자 소통
- 원 저자 코드 읽고 동작 이해

## Claude에게

- 긴 로그 확인: NM 로그, watch 로그, cgroup·메모리 모니터 출력
  - OCM·puff·shrink·reclaim 시점 타임라인 뽑기, 이상 구간 찾기
- 여러 회차 수치 집계 → 표·그래프
- 원 코드에서 위치 찾기 (클래스·줄 번호 grep)
- 내가 쓴 해석·문서 검토 (반론, 근거 누락, 논문 페이지 확인)
- 문서 형식 정리 (인덱스·링크·표)

## 규칙

- Claude는 결론을 먼저 내지 않는다 — 요약·수치만 주고 해석은 내가 먼저.
- 애매하면 내가 먼저 해보고 막히면 묻기.
